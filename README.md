## 🛠️ Getting Started

To run any demo locally:

1. Navigate to the desired demo directory:
   ```bash
   cd zomato-ai-demo
   ```

2. Follow the setup instructions in the corresponding demo's `README.md`.
3. Configure your `.env` file with your Naagmani API credentials or PST token.
4. Run the demo application and test out AI workflows!
